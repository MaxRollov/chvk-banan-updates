# ЧВК Банан лосось — загрузки для Android

Готовые APK приложения **ЧВК Банан лосось**. Исходного кода здесь нет — только сборки для установки.

## 📥 Скачать последнюю версию

**[➡ Перейти к последнему обновлению](../../releases/latest)**

На странице релиза, в блоке **Assets**, скачайте файл `CHVK-Banan-VPN-021126-8.apk`.

Если не уверены, какой из двух файлов брать, — берите **основной**, без `_sb` в названии.

| Файл | Что это |
|---|---|
| `CHVK-Banan-VPN-021126-8.apk` | **Основная сборка.** VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard |
| `CHVK-Banan-VPN-021126-8_sb.apk` | Сборка на другом ядре. Нужна только если в подписке есть **TUIC** |

Ставить обе сразу не нужно — достаточно одной.

## 📲 Как установить

1. Скачайте APK на телефон.
2. Откройте файл. Если Android спросит — разрешите установку из браузера/файлов («Неизвестные источники» для этого приложения).
3. Если приложение уже стояло — встанет **поверх**, подписки и настройки сохранятся.

Требуется Android 8.0 или новее, телефон на ARM64 (любой современный).

## 🔄 Как обновляться

Просто скачайте свежий APK по той же ссылке «последнее обновление» и поставьте поверх. Свои подписки заново вводить не нужно.

Проверить, что обновление встало: **«О приложении»** → версия и код сборки должны совпадать с указанными на странице релиза.

## ✨ Что умеет приложение

- Подключение по подписке (ссылкой) и по одиночной ссылке сервера
- Импорт обычного WireGuard-конфига `.conf`
- Маскировка трафика: REALITY + XTLS-Vision, uTLS-отпечатки браузеров
- Автоподбор лучшего сервера и ядра одной кнопкой
- Быстрое подключение: виджет, плитка в шторке, последний использованный вариант
- Исключения приложений из VPN, сценарии «Дом / Публичный Wi-Fi / Белые списки»
- Кнопка «Сообщить об ошибке» в разделе «О приложении» — если что-то сломалось, жмите её, отчёт прилетит разработчику сам

## ❓ Что-то не работает

В приложении: **«О приложении» → «Сообщить об ошибке»** — кратко опишите проблему, журнал приложится автоматически.

---

Сборка подписана постоянным ключом разработчика: обновления всегда ставятся поверх, подменить APK чужим нельзя — Android не даст установить сборку с другой подписью.
